# Arduino RFID RC522 Project

## Overview
This project is an RFID-based access control
system using Arduino and RC522 module.

## Components
- Arduino Board
- RFID RC522 Module
- RFID Cards
- LCD 16x2
- Jumper Wires
- Breadboard

## Circuit Design
The circuit was initially designed and tested
using Wokwi simulator.
